Shopping ▾
Redesign 2 · Slack Groups
The pill tab row is deleted. Sections become collapsible groups in one continuous scroll, exactly like Slack's channel sidebar — sticky headers, open-count badges, and a one-line peek of what's inside a collapsed group. You can see every section's state at once instead of tab-hopping to find out. The composer carries a destination chip ("Shopping ▾"), so adding to a different section never requires switching context first — this is the real win, and it makes the widget's quick-add and the share target land in the same mental model.

Cost: the biggest behaviour change of the five. Per-section drag-reorder still works inside a group, but cross-group drag is new work, and the "one big list" fights the current observeItems(sectionId) query — it needs a grouped query or N flows combined.
