Redesign 1 · Slack Rail — emoji sections
Sections are a permanent 70px rail: every one visible, one tap away, no horizontal scroll, open counts as red badges. Emoji replaces the letter tile; Ideas is shown with no emoji set, falling back to its initial on the solid section colour. The header and composer placeholder both echo the emoji, so a section reads the same everywhere.

Cost of the emoji: Section had no emoji field, so this was a schema 5 → 6 migration — one nullable emoji TEXT column, no backfill needed, plus an emoji picker in SectionNameDialog and the letter fallback when null. Per the repo's own rule, back up before running it. The widget's ClassicWidgetRenderer is RemoteViews, so it can show the emoji in a TextView but needs its own pass.

Row action bar: check / edit / move-to-section / delete. The first three replace hidden gestures you already have (tap circle, tap text — long-press on link rows — and swipe past 45%). Move-to-section is new functionality: Item.sectionId is a plain column, so it's a setSection() DAO method plus a position shift, no migration. It replaced the ⋯ from the first draft, which had nothing behind it.

Layout cost: 70px of 412 gone permanently; the list runs at 342px wide.
